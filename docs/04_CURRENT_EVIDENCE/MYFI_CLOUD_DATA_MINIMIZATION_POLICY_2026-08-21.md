# MYFI — سياسة تقليل بيانات Supabase (2026-08-21)

## الحكم التنفيذي

Supabase ليس نسخاً احتياطياً لإعدادات الهاتف. SQLite المحلي هو موضع الاحتفاظ
بتفضيلات الجهاز، والسحابة تحمل فقط ما يلزم لصحة السجل المالي والمزامنة بين
الأجهزة.

هذا التغيير لا يتصل بـSupabase ولا يغير Schema أو RLS أو بيانات أي حساب. لذلك
لا يحذف بيانات أُرسلت في الماضي؛ إزالة/تنظيف بيانات سحابية قائمة هو قرار وتشغيل
إنتاجي منفصل يحتاج تفويض المستخدم الصريح وخطة استرجاع.

## ما يُرسل

1. **السجل المالي:** الحركات بما فيها المبالغ والعناوين والملاحظات، المحافظ،
   التصنيفات، الديون، الأهداف، الالتزامات، الميزانيات، القواعد المتكررة،
   العملات وأسعار الصرف.
2. **بروتوكول المزامنة:** معرفات السجل/الكيانات/الجهاز، المراجعات، tombstones،
   المظروف التشغيلي، تسلسل الخادم و`restore_epoch`.
3. **إعداد مساحة العمل الوحيد:** `currency`، لأن تغيير عملة الأساس قيمة مالية
   لها قيود ومحاذاة للمحفظة.
4. **هوية الحساب منفصلة عن السجل المالي:** Supabase Auth يحتفظ بالبريد والجلسة؛
   الاسم واسم المستخدم والهاتف وصورة الحساب تستخدم `profiles`/Storage فقط ضمن
   نطاق هوية الحساب.

## ما لا يُرسل مطلقاً ضمن مزامنة مساحة العمل

- اللغة، الثيم، التدوير، صيغة التاريخ والدولة.
- ترتيب الصفحة والبطاقات والإجراءات، تبويب البداية، وضع الإدخال، وظهور الوحدات.
- إخفاء الأرصدة وتفاصيل الإشعارات، القفل الحيوي والمهلة، والموافقة المحلية.
- المحفظة الافتراضية، النطاق/نوع العرض، تفضيلات الإشعارات والتذكيرات.
- `avatarUri` أو `avatarPath` أو رقم الهاتف أو أي إعداد جديد غير موجود صراحةً
  في قائمة السماح.

## آلية المنع

- `src/lib/cloudWorkspaceMetadata.js` هو حدّ مركزي fail-closed: القائمة البيضاء
  تحتوي `currency` فقط.
- جميع مسارات V2 وV1 التوافقية تمرر إعداد مساحة العمل من خلال هذا الحد قبل
  كتابة الكيان/Outbox أو RPC `sync_user_data_v2`.
- التفضيلات المحلية تحفظ بجانب مساحة العمل في SQLite فقط، ولا تنتج outbox أو
  جدولة مزامنة عند تغيير اللغة أو الثيم أو الإشعارات.
- دمج سحابي لا يبدل تفضيلات الهاتف؛ يطبّق فقط حقول قائمة السماح فوق القيم المحلية.

## دليل التحقق المحلي

`npm.cmd run test:gate` في 2026-08-21: **92 passed, 0 failed, 11 skipped**.
يشمل عقداً يتحقق أن اللغة والثيم وبيانات الصورة والهاتف وتفضيلات الخصوصية لا
تدخل `canonicalWorkspaceCfg`، وأنها لا تصنع conflict سحابياً.

## قاعدة التغيير المستقبلي

لا يضاف مفتاح إلى قائمة السماح إلا إذا كان سبب مالي متعدد الأجهزة مكتوباً،
ومراجعة خصوصية، واختبار regression يثبت أنه لازم للمزامنة. الافتراضي دائماً
هو محلي فقط.
